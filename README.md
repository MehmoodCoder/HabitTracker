# HabitTracker
A responsive single-page Habit Tracker web app built with HTML, CSS, Bootstrap, and Vanilla JavaScript for the Dev Weekends Fellowship 2026 assessment. Features include weekly grid tracking, streak counters, and localStorage persistence.

# Habit Tracker - Dev Weekends Fellowship 2026

This is a simple single-page Habit Tracker web application built using HTML, CSS, Bootstrap, and JavaScript.

## How to Run the Project Locally
1. Download or clone this repository to your computer.
2. Open the folder and locate the `index.html` file.
3. Double-click the `index.html` file to open it directly in any web browser (Google Chrome, Microsoft Edge, etc.).
4. No installations or local servers are required.
